# Платформа раздачи подарков (профсоюз, Новый год)

Одноразовая платформа для розыгрыша призов на мероприятии.

- Подарки выдаются **только** тем, кто есть в списке участников.
- Каждый участник получает подарок **ровно один раз** (повторная выдача заблокирована).
- Выданный подарок **вычёркивается** из списка и привязывается к конкретному человеку.
- Все изменения хранятся в облаке и синхронизируются между всеми устройствами в реальном времени.

## Почему данные не потеряются и не разойдутся
- Единственный источник правды — база Postgres в **отдельном** проекте Supabase (создан специально, чтобы не трогать вашу основную платформу).
- Несколько волонтёров на разных телефонах видят одно состояние (realtime-подписка на таблицы).
- Выдача — атомарная функция `assign_gift` на стороне БД: блокировки строк + проверка «уже получил», поэтому два волонтёра не выдадут один подарок дважды и один человек не получит два подарка. Дополнительно: UNIQUE-индексы на `handouts(person_id)` и `handouts(gift_id)`, функции `SECURITY DEFINER`, триггеры-стражи на `received`/`status`, прямая запись в `handouts` для anon запрещена.
- При обрыве сети выдача ставится в очередь и отправляется автоматически; последние данные кэшируются локально.
- Кнопка «Скачать бэкап (JSON)» в шестеренке — делайте копию на всякий случай. Восстановление из бэкапа — атомарная замена всех данных через `restore_backup` (с подтверждением).
- Каждый шаг (выдача и отмена выдачи) записывается в **лог** со временем и именем оператора — проверить можно во вкладке «Лог», а также скачать CSV.

## Как пользоваться
Откройте `index.html` в браузере телефона/планшета. Сверху — счётчики: сколько человек получили и сколько подарков выдано; точка соединения показывает синхронизацию. При потере сети показывается баннер «оффлайн» и последние сохранённые данные.

- **Имя оператора** — поле сразу под счётчиками. Укажите имя один раз: оно будет записываться в лог каждой выдачи и отмены. Пока не задано — поле подсвечивается жёлтым.
- **Раздача** — введите ФИО → выберите человека → выберите подарок → «Выдать». Если человек уже получил, покажет что и когда, с кнопкой отмены. Если человека нет в списке — выдать нельзя.
- **Подарки** — весь список подарков с остатками и кем получен (вычёркнутые — выданы). Сверху поиск по названию или слот-номеру.
- **Люди** — весь список участников с отметками о выдаче; поиск по ФИО, телефону, комментарию.
- **Лог** — история выдач и отмен: выдача и отмена — отдельные записи со своими временами, связаны между собой (отмена показывает, когда и кем была выдача). Дата, время, человек, подарок, кто выдал / кто отменил. Фильтры «только выдачи / только отмены», поиск, выгрузка в CSV.
- **⚙️ Импорт** (шестерёнка в верхнем правом углу) — загрузка списка людей (вставить текст / CSV / Excel), добавление подарков (например, строки 119–151 из PDF), бэкап/восстановление, очистка, а также «Не удалось отправить» — операции, которые не прошли при отправке из офлайн-очереди. Возврат на прежнюю вкладку — кнопка «← Назад» вверху раздела или повторный клик по шестеренке.

## Импорт списка людей
Формат строк: `ФИО`, `ФИО; телефон` или `номер; ФИО; телефон`. Также CSV и Excel с колонками ФИО / телефон / номер (названия нестрогие). Нажмите «Предпросмотр», проверьте, затем «Импортировать». Дубликаты (по ФИО) пропускаются.
